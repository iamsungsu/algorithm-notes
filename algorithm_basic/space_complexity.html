공간 복잡도 Big-O Notation

O(1) 상수 공간

O(log n) 로그 공간

O(n) 선형 공간

O(n log n) 선형 로그 공간

O(n²) 이차 공간

O(2ⁿ) 지수 공간

시간 복잡도와 마찬가지로 공간 복잡도도 상수 시간을 무시하고 가장 높은 차수를 기준으로 빅오 표기법(Big-O Notation)을 사용하여 나타낸다. 공간 복잡도에서 상수는 입력값의 크기와 상관없이 항상 고정된 크기를 차지하는 변수나 배열을 의미한다. 고정된 크기(상수)는 무시하고, 데이터 크기에 비례하여 동적으로 늘어나는 메모리 공간만 측정하여 O(n)으로 표기한다. 만약 변수만 100개 사용하고 배열을 아예 안 쓴다면 공간 복잡도는 그냥 O(1)이 된다.

공간 복잡도의 구성 요소

공간 복잡도란, 알고리즘을 실행하고 완료하는 데 필요한 총 저장 공간량을 의미한다. 입력 크기에 따라 필요한 메모리의 양을 측정하는 것이다. 공간 복잡도는 크게 고정 공간, 가변 공간으로 나눤다. 고정 공간은 입력 크기와 상관없이 항상 일정하게 유지되는 공간이다 단순 변수, 상수 등이 포함된다. 가변 공간은 문제를 해결하기 이해 알고리즘이 실행되는 동안 동적으로 필요로 하는 공간이다.

공간 복잡도 표기법

O(1) : 입력 크기 n과 관계없이 항상 일정한 크기의 메모리를 사용하는 경우 (예: 단순 변수 몇 개만 쓰는 반복문)

# 변수 몇 개만 사용하는 경우
def get_sum(numbers):
    total = 0

    for num in numbers:
        total += num

    return total

O(n) : 입력 크기 n에 비례하여 메모리를 차지하는 경우 (예: 크기가 n인 1차원 배열 생성)

O(n²) : 입력 크기의 제곱에 비례하여 메모리를 차지하는 경우 (예: n * n 크기의 2차원 배열 생성)
