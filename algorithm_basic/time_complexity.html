Big-O Notation

O(1) 상수 시간

O(log n) 로그 시간

O(n) 선형 시간

O(n log n) 선형 로그 시간

O(n²) 이차 시간

O(2ⁿ) 지수 시간

시간 복잡도 최적화

O(n²)과 O(2ⁿ)은 입력 데이터가 많아질수록 처리 시간이 빠르게 증가한다. 단, O(n²)은 다항 시간이고 O(2ⁿ)은 지수 시간이다. 문제의 조건에 따라 더 효율적인 알고리즘을 선택할 필요가 있다.

O(n²)은 중첩 반복문에서 자주 나타난다. 이미 확인한 데이터를 set이나 dict에 저장하면 특정 문제에서 불필요한 반복 탐색을 줄일 수 있다.

O(2ⁿ)은 각 단계에서 두 가지 선택이 반복되는 완전 탐색 등에서 나타날 수 있다. 중복 계산이 있다면 메모이제이션으로 계산량을 줄일 수 있다.

메모이제이션 (Memoization)

한 번 계산한 결과를 저장해 두었다가 같은 계산이 필요할 때 재사용하는 방법이다. 피보나치 수열을 예로 살펴보자.

① 단순 재귀: O(2ⁿ)

def fib(n):
    if n <= 1:
        return n

    return fib(n - 1) + fib(n - 2)

② 메모이제이션 적용: O(n)

# 계산 결과를 저장할 딕셔너리
memo = {}

def fib(n):
    if n <= 1:
        return n

    if n in memo:
        return memo[n]

    memo[n] = fib(n - 1) + fib(n - 2)
    return memo[n]

중복 계산을 제거해 피보나치 수열의 계산량을 줄일 수 있다. 이처럼 부분 문제의 결과를 저장해 재사용하는 접근은 동적 계획법(Dynamic Programming, DP)의 대표적인 기법이다.

이진 탐색 (Binary Search)

정렬된 배열에서 중간값과 목표값을 비교해 탐색 범위를 매번 절반으로 줄이는 알고리즘이다. 시간 복잡도는 O(log n)이다. 

def binary_search(arr, target):
    left = 0
    right = len(arr) - 1

    while left <= right:
        # 중간 인덱스 계산
        mid = (left + right) // 2

        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            # 오른쪽 절반 탐색
            left = mid + 1
        else:
            # 왼쪽 절반 탐색
            right = mid - 1

    return -1

알고리즘 최적화를 위한 접근법

  1. 같은 계산을 반복한다면

    메모이제이션이나 동적 계획법(DP)을 고려한다.

  2. 같은 데이터를 반복 탐색한다면

    set, dict, 해시 테이블 등을 활용할 수 있는지 확인한다.

  3. 정렬된 데이터에서 값을 찾는다면

    이진 탐색을 사용할 수 있는지 확인한다.

  4. 중첩 반복문이 있다면

    정렬, 해싱, 투 포인터, 슬라이딩 윈도우 등으로 반복을 줄일 수 있는지 살펴본다.

  5. 이미 효율적인 표준 기능이 있다면

    직접 구현하기 전에 Python의 list.sort() 같은 기능을 활용할 수 있는지 확인한다.

핵심 정리

모든 문제에 적용되는 단 하나의 알고리즘은 없다. 문제의 입력 크기, 데이터의 특성, 시간 및 공간 제약을 분석해 적절한 알고리즘과 자료구조를 선택해야 한다.
