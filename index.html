알고리즘과 자료구조는 왜 공부해야 할까?

프로그래밍은 단순히 문법을 익히는 것에서 끝나지 않습니다
복잡한 문제를 효율적으로 해결하기 위해서는 알고리즘과 자료구조를 이해해야 하며,
그 원리를 깊이 있게 파악하기 위해서는 수학적 사고력도 필요합니다
단순히 코드를 작성하는 것을 넘어, 기술의 원리를 이해하고 스스로 문제를 해결하는 멋진 개발자가 되어봅시다

Algorithm & Data Structure

핵심 개념을 익히고 문제 해결에 적용

알고리즘 기초 시간 복잡도, 재귀, 정렬과 탐색 공부하기 자료구조 배열, 스택, 큐, 해시 등 공부하기 알고리즘 심화 그래프 탐색, 그리디, 동적 계획법 등 공부하기
알고리즘 문제 실습 공부한 알고리즘을 코딩 테스트 문제에 적용 페이지 준비 중
자료구조 문제 실습 상황에 적합한 자료구조를 선택하고 활용 페이지 준비 중
응용 문제 실습 여러 개념을 조합하여 문제해결 페이지 준비 중

이산수학 논리, 집합, 경우의 수, 점화식 등 컴퓨터 과학과 관련된 수학 페이지 준비 중
정수론 소수, 약수, 최대공약수, 나머지 연산 등 페이지 준비 중
