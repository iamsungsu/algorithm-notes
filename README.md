## 01 / PROJECT OVERVIEW

**Algorithm Notes**는 알고리즘 문제 해결에 필요한 이론과 자료구조의 동작 원리를 학습할 수 있도록 제작한 웹사이트입니다.<br>
단순한 개념 설명을 넘어, 각 알고리즘과 자료구조의 작동 방식 및 내부 원리를 이해하는 데 중점을 두고 있습니다.
